# Merge lessons

- Select parsers from decoded content, not filename extensions.
- Use one pipeline for CLI, upload, paste and API requests.
- A safety net must not depend solely on the detector it backs up.
- Compute verification state; never infer a clean badge from successful execution.
- Enforce export restrictions on the server as well as in the UI.
- Preserve doctor roles before replacing person mentions.
- Require numeric context for case identifiers; uniqueness hints are a separate category.
- Count applied edits separately from detected spans and visible tokens.
- Test original filename, wrong extension and paste paths for byte parity.
- Report quarantined and missing fixtures explicitly; neither proves medical preservation.
- Keep raw patient input out of browser persistence, logs and external services.
- Reject incomplete corpus gates rather than inventing oracle files.
- Quarantine is a last resort, not a substitute for sanitizing.
- Count in-memory repair attempts separately from replacements in published output.
- Require whole-content consistency before selecting a whole-file parser.
- Keep generic phone scanning line-bounded; only labeled phone grammar may cross lines.
- Re-check clinical and role context before applying an independent late redaction.
